# 페이지 영역 이름 지도

팡팡에듀 홈페이지(`index.html`)는 위에서 아래로 **6개 영역**이 쌓인 단일 스크롤 페이지다.
대화할 때 "어디를 고칠지"를 서로 빠르게 가리키기 위한 이름표 문서다. (예: "히어로의 부록 수치")

시각 버전은 발행된 Artifact로도 있으니, 눈으로 보고 싶으면 그쪽이 편하다.

## 전체 순서 (위 → 아래)

```
┌─────────────────────────────────────────────┐
│ 1. 네비게이션 바   header.nav                  │  로고 · 메뉴 · 도서 보기 · 햄버거
├─────────────────────────────────────────────┤
│ 2. 히어로 / 대문   section.hero  #top          │  큰 제목 · 소개 · 버튼 · 부록 수치 · 책 이미지
├─────────────────────────────────────────────┤
│ 3. 출판 도서       section  #books             │  시리즈 2개 · 도서 카드들
├─────────────────────────────────────────────┤
│ 4. 책 소개         section  #about             │  한자 어휘 설명 · 50~70% 강조 · 학습 흐름
├─────────────────────────────────────────────┤
│ 5. 연락처          section  #contact           │  이메일/전화/주소 · 소셜 링크
├─────────────────────────────────────────────┤
│ 6. 푸터            footer                       │  로고 · 저작권                    │
└─────────────────────────────────────────────┘
```

메뉴의 링크는 각 영역의 id로 이동한다: **출판 도서 → `#books`**, **책 소개 → `#about`**, **연락처 → `#contact`**.

---

## 1. 네비게이션 바 (NAV) — `header.nav`

화면 맨 위 고정 막대.

| 부분 이름 | 기술 이름 | 내용 |
|---|---|---|
| 로고 | `.brand` | 팡팡에듀 로고 + 이름 (누르면 맨 위로) |
| 메뉴 | `.nav-menu` (`#navMenu`) | 출판 도서 · 책 소개 · 연락처 링크 |
| 도서 보기 버튼 | `.btn.btn-accent.desk` | 주황 버튼 (데스크톱에서만 보임) |
| 모바일 햄버거 | `.nav-toggle` (`#navToggle`) | 모바일에서 메뉴 열고 닫는 3줄 버튼 |

## 2. 히어로 / 대문 (HERO) — `section.hero` (`#top`)

첫 화면 대문. 왼쪽은 글, 오른쪽은 책 이미지.

**왼쪽 `.hero-left`**

| 부분 이름 | 기술 이름 | 내용 |
|---|---|---|
| 작은 라벨(키커) | `.kicker` | "어휘력 팡팡 · 한자 어휘 학습지" |
| 큰 제목 | `h1` | "놀이처럼 배우는 한자 어휘의 힘" |
| 소개 문구 | `.lead` | 대문 아래 두세 줄 설명 |
| 버튼 묶음 | `.hero-cta` | 출판 도서 보기 / 브랜드 이야기 |
| **부록 수치** ⭐ | `.hero-stats` | 50~70% · 약 100개 · 약 80개 — *최근 모바일 겹침을 고친 곳*. 각 항목은 `.st`(숫자 `.num` + 설명 `.cap`) |

**오른쪽 `.hero-right`**

| 부분 이름 | 기술 이름 | 내용 |
|---|---|---|
| 태그 필 | `.hero-tagpill` | "어휘력 팡팡 · 우리집 시리즈" |
| 책 이미지 | `.hero-visual` | 우리집 시리즈 전권 이미지 |
| 캡션 | `.hero-caption` | "우리집 화장실 · 거실 · 주방" |

## 3. 출판 도서 (BOOKS) — `section` (`#books`)

시리즈 두 개가 각각 "제목줄 + 카드 묶음"으로 들어간다.

| 부분 이름 | 기술 이름 | 내용 |
|---|---|---|
| 시리즈 제목줄 | `.sec-head` | 라벨 `.label` + 제목 `h2` + 번호 `.idx` (예: 01 — 03) |
| 우리집 시리즈 | `.books-grid` | 도서 카드 3권 (3열) |
| 이게 이 뜻?! 시리즈 | `.books-grid.compact` | 도서 카드 2권 (좁은 2열) |
| 도서 카드 | `.book` | 표지 `.book-cover` · 상태 뱃지 `.badge`(판매중 `sale` / 출간 예정 `soon`) · 제목 `h3` · 설명 `.desc` · 구매 링크 `.buy` |

## 4. 책 소개 (ABOUT) — `section` (`#about`)

왜 한자 어휘인지 설명하는 영역. 왼쪽은 제목+강조 수치, 오른쪽은 본문.

| 부분 이름 | 기술 이름 | 내용 |
|---|---|---|
| 강조 수치 | `.stat-50` | 큰 "50~70%" + 설명 (`.n` 숫자 / `.c` 설명) |
| 본문 | `.about-body` | 큰 문단 `.big` + 설명 문단 |
| 학습 흐름 | `.flow` | 정확한 뜻 이해 → 확장 어휘 → 색칠·미로찾기 놀이 활동 |
| 특징 칩 | `.chips` | 색칠하기 · 미로찾기 · 스티커 104개 · 그림카드 89개 |

## 5. 연락처 (CONTACT) — `section` (`#contact`)

문의 정보와 소셜 링크. 왼쪽/오른쪽 두 칸.

| 부분 이름 | 기술 이름 | 내용 |
|---|---|---|
| 왼쪽 정보 | `.contact-left` | Email · Phone · Address (`.cinfo` 안의 `.row`들) |
| 오른쪽 소셜 | `.contact-right` | 소셜 링크 `.sns` (Instagram · Threads · LinkedIn) + 안내문 `.cta-note` |

## 6. 푸터 (FOOTER) — `footer`

맨 아래 마무리 줄.

| 부분 이름 | 기술 이름 | 내용 |
|---|---|---|
| 로고 | `.foot-brand` | 팡팡에듀 로고 + 이름 |
| 저작권 | `.copy` | Copyright © 2026 팡팡에듀 · www.pangpangedu.com |

## 참고

- 반응형 분기점(화면 폭): **1000 / 860 / 520px**. 520px 이하가 좁은 휴대폰. 색·간격은 `css/style.css`의 `:root` 변수(토큰)가 기준.
- 이 문서는 마크업이 바뀌면 함께 갱신한다. 관련 문서: 브랜드 컬러 `docs/brand.md`, 방문 분석 `docs/analytics.md`.
