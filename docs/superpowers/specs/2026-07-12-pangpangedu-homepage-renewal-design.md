# 팡팡에듀 홈페이지 리뉴얼 · 설계 문서

- 작성일: 2026-07-12
- 상태: 승인됨 (구현 계획 작성 단계)
- 선택 시안: 시안 11 · 모던 스위스 흑백

## 1. 배경 및 목표

팡팡에듀는 초등 저학년 대상 한자 어휘 학습지 "어휘력 팡팡" 시리즈를 출간하는 출판사다.
현재 홈페이지는 `Work/web`(GitHub 저장소 `dmorucom/web`, GitHub Pages, 도메인 `www.pangpangedu.com`)에
Bootstrap 5 기반 단일 페이지로 서비스 중이다.

이번 작업의 목표는 **기능 확장이 아닌 디자인 리뉴얼**이다. 기존 콘텐츠 구조(홈 / 출판 도서 /
책 소개 / 연락처 / SNS)를 유지하면서, 모던하고 절제된 "스위스 흑백" 디자인으로 전면 교체한다.

성공 기준:
- 시안 11의 디자인 언어가 실제 사이트에 충실히 구현된다.
- 데스크톱·태블릿·모바일에서 레이아웃이 깨지지 않는다.
- GitHub Pages로 배포 가능한 순수 정적 사이트다.
- 기존 사이트는 롤백 안전망으로 보존된다.

## 2. 기술 구성 결정

- **정적 사이트 (순수 HTML/CSS)**: 빌드 도구·프레임워크 없이 HTML/CSS로 구성한다. 상호작용이
  필요한 최소 부분(모바일 네비 토글, 부드러운 스크롤)만 vanilla JS로 처리한다.
- **Bootstrap 제거**: 기존의 Bootstrap 5 + Bootstrap Icons + jQuery 의존성을 걷어내고,
  시안 11의 자체 CSS 디자인 시스템으로 대체한다. 아이콘은 인라인 SVG 또는 텍스트로 처리한다.
- **단일 스크롤 페이지**: 다중 페이지 없이 앵커 기반 단일 페이지를 유지한다.
- **폰트**: Google Fonts의 Noto Sans KR (weight 300~800).

근거: 콘텐츠 규모가 작고 갱신 빈도가 낮으며 GitHub Pages 정적 호스팅과 맞물려, 프레임워크
도입은 과잉이다. 순수 정적 구성이 가장 단순하고 견고하며 유지보수가 쉽다.

## 3. 파일 구조 (`Work/pp-web`)

## 4. 디자인 시스템 (시안 11 기준)

- **색상**: 화이트(#ffffff) 배경, 니어블랙(#1a1a1a 계열) 텍스트, 단일 포인트 컬러 퍼플 #7b2d8e.
  포인트 컬러는 링크·강조·CTA 등에 절제해 사용한다.
- **레이아웃**: 스위스 그리드 규율, 넓은 여백, 1px 얇은 구분선, 명확한 타이포 위계.
- **타이포그래피**: 큰 헤드라인과 넓은 자간의 소형 레이블 대비. Noto Sans KR.
- **반응형**: 데스크톱 기준 레이아웃 → 모바일(~860px)에서 네비 메뉴 접힘, 카드 그리드 1~2열로 축소.
- **인터랙션**: `scroll-behavior:smooth`, 호버 상태(링크·카드·버튼).

기준 파일: `Work/web/mockups/option11-swiss-mono.html` (구현의 시각적 기준으로 참조).

   모바일에서 햄버거 토글.
2. **히어로**: 킥커/배지, "어휘력 팡팡 · 놀이처럼 배우는 한자 어휘" 헤드라인, 짧은 설명,

## 6. 자산 (images)

`Work/web/images`에서 사용 자산을 `pp-web/images`로 복사한다: `logo.jpg`, `book.jpg`,
`book_bathroom.jpg`, `book_livingroom.jpg`, `book_kitchen.png`, `book_myroom.png`,
`main-bg.jpg`. 미사용 자산(blog*, service*, sns-bg, news-bg 등)은 복사하지 않는다.

## 7. 배포

- `Work/pp-web`을 새 Git 저장소로 초기화하고, GitHub의 신규 리포지토리에 push한다.
- 해당 리포에서 GitHub Pages를 활성화한다.
- `CNAME`에 `www.pangpangedu.com`을 포함한다.
- **도메인 DNS 전환은 별도 단계**로 분리한다. 새 사이트가 GitHub Pages 임시 URL에서 정상
  동작함을 확인한 뒤, 준비되면 도메인을 새 저장소로 전환한다.
- 기존 `dmorucom/web` 저장소는 삭제하지 않고 보존한다(롤백 안전망).

## 8. 범위 밖 (YAGNI)

이번 작업에서 하지 않는 것: 블로그/CMS, 온라인 결제·장바구니, 다국어, 문의 폼 백엔드,
관리자 페이지, 애널리틱스 고도화.

## 9. 열린 항목 / 후속

- GitHub 신규 저장소 이름 (미정 — 배포 단계에서 확정).
- 도메인 DNS 전환 시점 (사이트 확인 후 별도 진행).
